Built so typing never waits

Neon draws and submits each keystroke as soon as it handles it, without waiting for the next display refresh. Syntax highlighting reparses in the background, and only the editor redraws while you type.

Metal

Drawn on the GPU with GPUI, the framework behind the Zed editor.

Native

Written in Rust with no web view. About 16 MB on Apple Silicon.

Large files

Parsing runs off the main thread, so long documents stay responsive.

Everything a folder of notes needs

Zen Mode

The document alone, full screen. The paragraph you are writing stays bright while the rest fades. ⌃ ⌘ Z

Outline

The sidebar lists your headings and lights the section you are in. Write [TOC] for a table of contents.

Search the folder

Match case, whole word and regular expressions, with unsaved edits included.

Git in the sidebar

See changes word by word, then stage, commit and push. Browse history as a branch graph.

Tabs

Each tab keeps its own edits, undo history and scroll position. Neon reopens your last folder at launch.

Export

HTML, PDF or Word, in the preview's font, with local images embedded.

Linting

⌥ ⇧ F fixes spacing, headings and lists in one undoable step. A .neonlint.toml sets rules per folder.

Light and dark

Themes follow the system. Pick separate fonts and sizes for the editor and the preview.

Install Neon

Free for macOS 11 or later, on Apple Silicon and Intel.

  1. Download the latest release.
  2. Open the disk image and drag Neon to Applications.

Neon is signed and notarized, so macOS opens it without a warning. It updates itself and refuses any update that is not signed.

Check that a download was built by the release workflow:

$ gh attestation verify Neon-0.21.0-macos.dmg --repo michaelmjhhhh/neon

Or build it from source, with Xcode and rustup installed:

$ git clone https://github.com/michaelmjhhhh/neon
$ cd neon && cargo run --release

Start writing

Open a folder of Markdown files and Neon picks up from there.
